{{ _("What is stored") }}

{{ _("Mostly the ID Discord assigned you. An ID on its own says nothing; it is the key each feature uses to remember what belongs to you. Attached to it, depending on what you actually use:") }}

  • {{ _("Settings you set for yourself, such as your profile card's background, font and colours.") }}
  • {{ _("Counters a feature needs to work: experience and level, messages counted, time spent in voice, stars given and received, your balance.") }}
  • {{ _("Things you created, so the bot knows whose they are — playlists, reminders, and the like.") }}
  • {{ _("Moderation records, where a server's staff have used those features: warnings, notes, mutes and their reasons.") }}
  • {{ _("Message content, only where a feature cannot work without it — a logging channel a server has switched on, or a quoted or pinned message.") }}

{{ _("Server settings are stored against the server's ID in the same way, and are set by that server's staff rather than by you.") }}


{{ _("Why it is stored") }}

{{ _("Because the features would not work otherwise. A level card cannot show your level without a level, and a warning that vanishes on restart is not a warning. Nothing here is collected to build a profile of you, and none of it leaves the server the bot runs on.") }}
